## ✨ About The Project

This project is my personal portfolio website, designed to present my experience as a **Frontend / Full Stack Developer**.

The goal is to create a modern, fast and interactive experience where visitors can explore:

- My skills and technologies
- Selected projects
- Professional experience
- Contact information
- Technical articles and content

The project focuses on clean architecture, scalability and modern frontend practices.

# 🚀 Getting Started

## Clone the repository

```bash
git clone git@github.com:marioestima/my-portifolio.git
```

Enter the project:

```bash
cd my-portifolio
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
